# 本地安装与更新

安装包适用于Windows x64，每家公司在自己的设备上运行；这是独立商业化候选，不自动接入现有正式3.0账本。

首次使用：安装后打开桌面“企业项目收付款管理 本地版（候选）”，创建公司主账号。单机默认服务仅监听127.0.0.1。多人使用时，在一台长期运行的电脑中切换主机模式，员工通过“系统 → 使用模式与网络设置”填写主机地址或连接码。防火墙放行由公司管理员决定，软件不静默修改防火墙。

更新步骤：

1. 在主机导出完整备份（包含附件），放到另一块磁盘，并确认备份可以恢复。
2. 记录当前版本，关闭本地版所有窗口。
3. 核对新安装包的SHA-256摘要，运行安装更新包。
4. 打开软件，核对原账号、项目、往来单位、收付款流水和抽样附件。
5. 团队模式下确认所有员工均能连接同一主机。

默认程序位置：`%LOCALAPPDATA%\Programs\EnterpriseProjectManagerLocal\versions\版本号`。
默认数据位置：`%APPDATA%\enterprise-project-manager-local\business-data`。
默认附件位置：`%APPDATA%\enterprise-project-manager-local\project-files`。
连接公司主机时，业务资料由主机保存；员工电脑只保存连接设置和登录会话。

安装和卸载不清空上述业务目录。删除AppData是另一个不可逆的数据管理动作，不能用“重装软件”代替备份恢复。当前卸载还会保留历史程序版本以便排查。

从旧3.0接入时，应先核验备份格式、目录与账号兼容性，再在副本演练；当前候选不自动探测或导入用户现有正式数据。NAS主机更新需专门的服务器包，员工客户端安装包不代替NAS部署。
