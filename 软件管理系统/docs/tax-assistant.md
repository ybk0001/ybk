# 可选税务助手 · rc.4

用于3—5人公司的业务资料整理和会计交接。默认关闭，仅主账号可在“系统设置 → 可选功能”启用，然后从“经营报表 → 税务助手”进入。停用会收起入口，核对记录保留。每家公司独立保存，不需要税务云账号。

## 如何使用

1. 选择资料月份。开票提醒包含跨月未处理项目；其他资料按各记录的业务日期归集，这不是税款所属期判断。
2. 开票提醒直接进入对应项目收付款。已有“已开票”历史状态不会催促重复开票。供应商票据检查提示未关联票据、候选票据和合同/订单附件核对，是否适用由会计判断。
3. “票据登记”复用原有发票账本，可登记、导入、指定或分配项目、关联发票原件。已有登记无需再次录入；登记完成后刷新资料检查。项目普通文件不会冒充某张发票的已关联原件。
4. “会计确认”逐项填写核对说明，再记录已核对。切换分类和刷新会保留当前窗口草稿；未提交草稿不会在退出程序后恢复。业务资料变化后，原确认会显示需重核，并保留旧说明供参考。
5. “月度资料包”先预览再导出ZIP。默认只有业务摘要、CSV清单、核对记录和参考来源；勾选后才包含本月关联项目的发票/合同文件及明确关联原件。预览列出文件名和大小，资料变化则要求重新预览。最大500MB附件，文件校验清单内含SHA256。公司自行决定交付对象，软件不自动发送。
6. “官方参考”离线显示随包提供的摘要、适用范围、发布信息与入口核对日期。用户主动点击才打开官网，不附带公司账本、账号或查询内容。离线摘要不是实时有效政策保证，具体问题请会计通过所在地电子税务局或12366核对。

## 数据与边界

- 助手直接读取现有项目、发票、付款、回款、费用与项目附件；仅功能开关和人工核对记录新增存储，日常业务没有第二套录入。
- 功能开关在公司主机settings.json；核对记录在tax-assistant-reviews.json，完整备份与每日快照均包含记录。异机完整恢复不会自动启用目标公司的助手。
- 功能关闭和员工账号均无法调用助手接口。记录保存检查业务指纹和核对记录版本，拒绝旧页面覆盖新资料。
- 资料包只含选定业务字段，不含账号密码、会话或完整用户库；不是完整备份，也不是纳税申报表。票据与合同本身含公司资料，请由公司自行保管。
- 不自动判断税率、税额、抵扣、优惠或申报日期，不连接税务申报接口。合同文件缺失提示只是业务核对事项。
- 月度归集以账本现有记录日期为准；不自动补齐线下资料或推断无记录业务。
- 原正式3.0与NAS服务不在此次候选更新范围内。员工客户端更新不等于NAS服务更新；旧服务器没有助手接口时，入口自动隐藏。
