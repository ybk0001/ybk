# 候选运行时与第三方清单

本地版3.1.0-rc.3构建使用工作区已有的Electron44.4.3运行时，未联网下载新运行时。

发行包含：

- Electron运行时自带的 `LICENSE`。
- Chromium及关联组件声明 `LICENSES.chromium.html`。
- 已安装的NSIS3.0.4.1用于生成Windows安装更新包。
- 服务代码使用Node内置模块；源代码的税务/流水等兼容模块仍保留，但当前不新增税务导航。

发行文件逐项摘要位于程序目录 `release-manifest.json`，安装包摘要位于同名 `.sha256`。依赖授权完整性、源代码权属和商标标识尚需商业发布前签收；本清单只是构建实况记录，不替代授权审查。安装包当前未签名。
