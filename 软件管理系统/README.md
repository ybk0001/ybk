# 企业项目收付款管理 本地版

商业化候选：3.1.0-rc.6，面向3—5人的广告制作、印刷与外协团队。每家公司独立部署、独立账本；厂商不设集中业务云、不自动上传资料、不自动下载安装更新。可选税务助手默认关闭，主账号在“系统设置 → 可选功能”启用后，从“经营报表 → 税务助手”进入。详见 docs/tax-assistant.md。rc.6 改进账本占用和启动失败提示，并避免在切换账本后沿用上次登录账号。

源码基于与现有NAS相符的维护后端，加上已验收的release-r3布局。此目录是独立候选，不替换用户现有3.0程序或NAS数据。

程序与数据目录分离：安装在当前Windows用户的LocalAppData/Programs，业务数据和附件位于AppData/enterprise-project-manager-local。更新程序不移动或初始化既有账本；升级前仍须导出完整备份。卸载保留业务数据。

支持单机使用、公司内一台电脑作为主机供其他电脑连接，以及连接公司自己的NAS。多人必须连接同一个服务，不得各自启动服务读取同一共享JSON目录。NAS升级使用单独的服务器发行包，不能靠员工电脑的安装包更新NAS。

商业发布尚需完整升级演练、安全与恢复验收、安装包签名及第三方授权清单等，当前不得标记为正式可售。

已补齐：独立离线安装更新包、固定产品数据目录、程序按版本安装、同公司服务网络限制、上传中断原附件保护，以及5客户端并发保存与收付款余额回归。已有完整备份的异机恢复和损坏包拒绝测试；详情见 docs/product-boundary.md 与 docs/local-install-and-update.md。

构建：设置 NSIS_COMPILER 指向已有 makensis.exe，运行 npm run build；Electron运行时取同工作区已安装的固定44.4.3，不联网下载。源码与安装包构建按明确清单取文件，发行内不含公司或测试账本。
